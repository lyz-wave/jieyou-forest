# 思考层不做内容兜底，失败一律呈现为「未完成」

架构 v1 让承接、三视角、折返镜、裁决四层全都能秒切到内置示例稿。但 PRD §10 的原文是「思考超时：显示未完成，允许重试或回到休息，不伪造三视角」——只有承接层允许使用「明确标为通用提示」的兜底文本。

决定：承接层失败可以使用内置示例稿，但必须在同一屏上标明这不是针对本次输入写的；思考层失败一律显示「未完成」，绝不填充示例稿。现场担心翻车时，由演示者在口头说明之后切预录视频，而不是让界面假装生成成功。

理由：这个产品的全部主张是「经过你同意才提问」。一个在失败时假装成功的界面，恰好推翻了它自己——而这正是评审最容易一句话问穿的地方。
