# 安全闸门三级判定，保守的含义是「不辩论」而不是「弹窗」

架构 v1 只有一句「关键词先判，模型再判，命中即中断」。它有两个洞：模型不可用（正是「可选出站」的默认态）时闸门退化为纯关键词，误伤率高；命中之后该给用户看什么，完全没写。PRD §8.2 的要求是「不能依赖单个敏感词」「用户能更正误判」「无法判断时采取保守支持，而非继续辩论」。

决定分三级：L1 明确危险 → 固定支持页，暂停一切娱乐与挑战，展示赛前核验过的地区资源；L2 疑似或无法判断 → 不弹危机页，静默关闭思考入口、承接语气降为纯支持；L3 → 正常流程。三级都提供更正入口，更正后只恢复休息路径。

三条硬规则：模型缺席不等于无法判断，关键词独立工作，模型只能把 L3 升级为 L2、永远不能把 L1 降级；更正永不等于解锁；关键词表与阈值外置成配置文件，以便用合成用例回归。

## Consequences

未核验的危机资源不得上线，而无人在 PRD §15 里认领这件事。在有人认领并核验之前，本应用不得开放任何真实情绪的公测；合成数据的演示不受影响。
