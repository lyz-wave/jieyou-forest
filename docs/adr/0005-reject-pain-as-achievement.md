# 拒绝把痛苦做成勋章：删除 golden_scar 及同类机制

架构 v1 的数据模型里有一个 golden_scar（金色伤疤）字段，暗示「伤得越深、留下的痕迹越珍贵」。它与 PRD §8.1 直接冲突：不浪漫化痛苦、不因强烈情绪或反复受伤解锁稀有奖励、不使用「每一次枯萎都是下一次更粗壮的理由」这类话术。

决定：删除该字段以及一切同类机制——情绪强度奖励、连续打卡、稀有外观、深夜使用成就。年轮只有陪伴年轮与行动年轮两类，都由用户自愿产生，与情绪强度无关。

理由：这类机制的吸引力恰恰在于它「看起来很有意义」，所以以后一定会有人想加回来。把它记在这里，是为了让下一个人先看到「为什么不行」，而不是重新论证一遍。
